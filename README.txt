SPEEDTECH STATIC WEBSITE

Upload this ZIP to your domain document root in cPanel (usually public_html) and extract it. index.html must be directly in the document root. Back up existing site files before replacing them.

No installation or database is required. Open index.html locally to preview.

Edit index.html for page content, style.css for styling and app.js for products and the demo parts finder. Assets are in assets/. Product data and compatibility selections are illustrative. WhatsApp enquiries are supported; backend, live inventory, checkout and payment processing are not included. Google Fonts loads externally with system-font fallback.
